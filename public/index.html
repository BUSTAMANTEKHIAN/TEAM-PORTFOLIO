About

Small team, serious work.

DEV_STUDIO is a multidisciplinary student team of developers and designers. We turn briefs into working websites, applications, and visual systems.

Work is split across frontend, backend, full stack, and design. Projects in this portfolio include commerce, inventory, Firebase-powered sites, API work, and interface design.

We collaborate in Git, design in Figma, and ship with HTML, CSS, JavaScript, Node.js, Express, and MySQL — plus Firebase, Python, and Java where a project needs them.
